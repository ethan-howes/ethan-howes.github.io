# PROJECT.md — Project Context

Full context for this project so any session starts from a correct
understanding without re-explanation.

---

## What this project is

A **personal technical blog and portfolio site**, hosted on GitHub Pages via Jekyll.
A minimal, text-first site for publishing technical deep-dives on personal projects.

The goal is to have:
- A **home page** with a profile photo, bio, and activity feed
- A **projects listing page** showing each project with a thumbnail and description
- **Per-project blog posts** with full technical write-ups: design decisions,
  architecture diagrams, benchmark tables, code snippets, and results

---

## Technology

| Layer      | Choice                      | Notes                                               |
|------------|-----------------------------|-----------------------------------------------------|
| Generator  | **Jekyll**                  | Static site generator                               |
| Hosting    | **GitHub Pages**            | Free, compiles Jekyll automatically on push         |
| Markup     | **Markdown (kramdown/GFM)** | All content files are `.md`                         |
| Styles     | **SCSS**                    | One file: `assets/css/style.scss` (mostly plain CSS)|
| JS         | **highlight.js + MathJax**  | CDN-loaded in `base.html`; used by blog posts       |
| Fonts      | **Google Fonts (CDN)**      | `Crimson Text` (serif) + `Source Sans 3` (sans)     |

Deploy: push to `yourusername.github.io` repo, enable Pages in Settings.
Local preview: `bundle exec jekyll serve` (requires Ruby + Bundler).

## Key design decisions

### Visual style
- Cream background `#f5f4ef`, black text `#000`
- Content column: `768px` (`.container`), or `1100px` (`.container-wide`, `wide: true`)
- `.article-wrapper` padding `48px 24px`; `.site-header` / `.site-footer` padding `24px` / `32px 24px`
- Font roles:
  - `Crimson Text` (serif) — nav title, big page `.title` (60px / 40px mobile), `.content h2`, `.project-title`
  - `Source Sans 3` (sans) — nav links, `.content` body (18px / 1.625), `h3`/`h4`/`h5`
  - `ui-monospace` — footer, `.meta`, `.subtitle .mono`, `a.profile-link`, inline `code`
- Links in `.content`: `#000` underlined, `opacity: 0.7` on hover; footer/nav links `#555`/`#000`, underline on hover
- All typography is **scoped under `.content`** — markdown output only gets styled inside that wrapper
- `border-radius` only on small inline things (`code`, `pre`, `.skill`, images in `.project-image`), never on layout
- Mobile breakpoint at `768px`

### Navigation
Two-item nav, identical across all pages, driven by `_data/navigation.yml`:
```
[Site Title]                      Home  Projects
```
- Brand link (left): `.site-title`, `Crimson Text` 24px, `color: #000`
- Nav links (right): `.nav-links a`, `Source Sans 3` 16px; `.active` class (set when `page.url == link.url`) and `:hover` both add an underline

### Home page (`index.md`)
- `layout: page` — content is rendered inside `.content`
- Opens with a `.profile-block` div: `<img class="profile-img">` + `<a class="profile-link">LinkedIn</a>`
- `.profile-block` floats **right** at ≥768px (30% width, min 330px), centers above the bio below that
- `.profile-img` is a plain rectangle (~300px, no border-radius) with `20px` padding
- Bio: 2–3 short paragraphs that wrap around the floated photo
- Raw `<h3> Activity</h3>` (kramdown won't wrap a raw tag), then a plain `- **Month Year:** ...` markdown list — no custom divider CSS, just `.content li` spacing

### Projects listing (`projects.md`)
- Front matter: `layout: page`, `show_title: true`, `wide: true`
- Uses a raw **HTML `<table class="project-table">`** — one `<tr>` per project, two `<td>`s:
  - `.project-image-cell` — `<img class="project-image">` (or an autoplay `<video>`)
  - `.project-content-cell` — `.project-title`, `.skills` with `<span class="skill">` pills, a description `<p>`, `.project-links`
- `.project-links` items are written as `[<a href="...">blog post</a>]` — literal square brackets around each link
- Stacks vertically at ≤768px

### Project blog posts (`projects/your-post.md`)
- Front matter fields:
  ```yaml
  layout: post
  title: "Short Title"        # → h1.title
  subtitle: "Full Name"       # → renders as "Full Name — blog" (mono tag) below the title
  date: 2025-06-01            # → "June 01, 2025" in the .meta grid
  repo: repo-name             # → Code link to github.com/username/repo-name (omit if no code)
  permalink: /projects/slug/
  ```
- `post.html` renders `.article-header` (`.title`, `.subtitle` + `.mono`, `.meta` rows for
  Published / Email / Code) then `<div class="content">{{ content }}</div>`
- `.meta` is a flex column of `.meta-row` (each: `.meta-label` + `.meta-value`), all monospace
- Data tables (comparisons, benchmarks) are styled by `.content table` (header shading, row striping, bottom borders)
- Images use plain Markdown: `![alt](url)`, caption as next line `*Fig. N Text.*` in italics
- Fenced code blocks are syntax-highlighted by highlight.js; `\( \)` / `\[ \]` math by MathJax

### SCSS critical notes
- `style.scss` **must** have `---\n---` front matter or Jekyll won't compile it to `style.css`
- The file is mostly plain CSS (valid SCSS). Keep the `.site-*` / `.container` /
  `.article-*` / `.content` / `.meta-*` naming convention documented in its header comment.
- All markdown/body typography lives under the `.content` selector — a page or post that
  doesn't wrap its body in `.content` will render unstyled text

### Site variables (all in `_config.yml`, used as `{{ site.* }}`)
```yaml
title:             # → nav brand name, page titles
email:             # → footer link, post .meta row
github_username:   # → footer link, post .meta Code URL
linkedin_username: # → home page LinkedIn link, footer
```

## Adding a new project — checklist

1. Add an image (GIF or PNG, ~300×225px) to `/images/`
2. Copy a `<tr>` block in `projects.md` and fill in image, title, `.skill` pills, description, links
3. Copy `projects/sample-project.md`, rename to `projects/your-slug.md`
4. Fill in front matter: `title`, `subtitle`, `date`, `repo`, `permalink`
5. Write the post body — see `sample-project.md` for the section template
6. Add an entry to the Activity list in `index.md`

## Constraints — do not

- Do not swap the fonts or palette (`Crimson Text` + `Source Sans 3`, cream `#f5f4ef`)
- Do not remove the highlight.js / MathJax / Google Fonts includes from `base.html`
- Do not change the layout set (`base.html` + `page.html` + `post.html`) or the
  `_data/navigation.yml` nav mechanism
- Do not add animations, shadows, or border-radius on layout elements (small inline
  elements like `code` / `.skill` pills are fine)
- Do not move body typography out from under the `.content` selector
- Do not add a `_posts/` folder — project posts live directly in `projects/`
